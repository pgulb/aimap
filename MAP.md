# aimap — Architecture Map

## Overview

`aimap` is a CLI tool written in Go that scans Go and Python projects and generates `MAP.md` — a symbol map of functions, objects, methods, variables, and their line ranges. It is designed to help AI agents (and human contributors) locate code symbols quickly without full-repository searches.

The architecture is a pipeline: CLI entry → config loading → file tree scan → source parsing → symbol output.

**This document has two sections:**

1. **Architectural overview** (above) — manually maintained. Describes the project structure, packages, key types, and cross-module dependencies.
2. **Symbol map** (below) — **automatically generated** by running `aimap` in the project root. Lists every function, method, type, variable, and constant with file paths and line numbers.

To regenerate the symbol map section:

```bash
go run ./cmd/aimap/
```

## Packages

| Package | Files | Responsibility |
|---|---|---|
| `cmd/aimap/main.go` | 1 | CLI entry, flag parsing, pipeline wiring |
| `internal/symbol/` | 2 | `Symbol` struct (Name, Kind, FilePath, LineStart, LineEnd, Comment, Parent), `SymbolKind` enum (Function, Method, Struct, Interface, Type, Variable, Constant, Class) |
| `internal/ignore/` | 2 + tests | `Matcher` with built-in ignores + `.aimapignore` gitignore-style parsing |
| `internal/scanner/` | 1 + tests | `Scanner` walking directory tree via `filepath.WalkDir`, classifying `.go`/`.py`/other |
| `internal/config/` | 1 + tests | `Config.Load()` — resolves root, loads `.aimapignore`, returns `*Config` with `*Matcher` |
| `internal/parser/` | 2 + tests | Go parser via `go/ast`; Python parser via line-based state machine |
| `internal/output/` | 1 + tests | Render symbols to markdown grouped by language section then file path |

## Key Design Decisions

- **No external dependencies** — uses Go standard library exclusively
- **Single-binary CLI** — no config file required (optional `.aimapignore`)
- **Output to `MAP.md`** — overwrites symbol listing below the SYMBOL MAP marker, preserves architectural overview above it
